A compatibility and reliability update for kmpYT on Android, JVM desktop and iOS.

- Desktop Chromium startup reads the assigned debugging endpoint from the owned
  browser profile. This works with Windows GUI browser processes that do not
  send a startup banner to standard error.
- JVM and Android download checkpoints recognize symbolic links before cleanup
  and replace checkpoint receipts atomically. A failed update preserves the
  last committed receipt, and successful downloads preserve the reusable lock.
- CI exercises the desktop browser and media tests on Linux, macOS and Windows,
  Android instrumentation on API 29 and 35, and Kotlin and UIKit-hosted WebKit
  tests on Apple Silicon and Intel simulators.
- Maven releases include the root, Android, JVM, and three iOS publications
  under `io.github.apdelrahman1911.kmpyt`.

See the [integration and platform guide](https://github.com/Apdelrahman1911/kmpYT#readme).
